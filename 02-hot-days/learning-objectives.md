# Learning Objectives: Hot Days

By the end of this module, you should be able to...

- Open a text file with `open()` and read it one line at a time.
- Use a `with` block so the file is closed automatically when you are done.
- Loop over the lines of a file with a `for` loop.
- Strip whitespace and the trailing newline off a line of text with `.strip()`.
- Convert a line of text into a number with `float()`.
- Compare two numbers with `>`, and understand the difference between "greater than" and "greater than or equal to".
- Use an `if` statement to run code only when a condition is true.
- Keep a running total in a counter variable, initializing it before the loop and adding to it inside.
- Refer to a file that lives in a subfolder using a path like `data/sensor_readings.txt`.
- Combine the above to read a data file, filter its rows by a condition, and report a formatted count.
