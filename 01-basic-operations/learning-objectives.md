# Learning Objectives: Basic Operations

By the end of this module, you should be able to...

- Assign values to variables, including assigning several at once on a single line.
- Recognize and use Python's core scalar types: `int`, `float`, and `str`.
- Convert between types explicitly with `int()`, `float()`, and `str()`, and predict when a conversion loses information.
- Apply the arithmetic operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`.
- Evaluate an expression by hand using Python's operator precedence rules, and use parentheses to override them.
- Measure a string with `len()`, access single characters by index (including negative indices), and take substrings by slicing.
- Build output strings with f-strings, embedding variables and expressions inside them.
- Print results to the console in an exact, specified format.
- Combine the above to solve a multi-step problem: take given values, convert and compute, then report a formatted answer.
