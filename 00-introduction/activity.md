# Activity 00: Getting oriented

The primary goal of this first activity is to get you reading the
lesson and comfortable with how these materials are organized, since every
module in this course follows a similar layout.

## Step 1: Open the lesson

In this same folder (`00-introduction`) there is a file called
`00-introduction.html`. Open it in a web browser:

- Find `00-introduction.html` in your file manager and double-click it — it
  should open automatically in your default browser (Firefox, on Mint).
- If double-clicking doesn't open a browser, right-click the file, choose
  **Open With**, and pick a browser.

Once it's open, you'll see a page with a "Contents" sidebar on the left and
**Back** / **Next** buttons at the bottom — you can click a section in the
sidebar to jump to it, or use Back/Next (or the Left/Right arrow keys) to move
through the lesson one section at a time.

## Step 2: Read it

Read through the whole introduction now, start to finish. Don't worry about memorizing commands, but you should follow the instructions and physically type the new commands and code presented (not copy+paste). You may come back to
specific sections as you work through later activities, but this is to get you started.

## Step 3: Learn the folder layout

Every module in this course — including this one — is a single folder
containing mostly the same set of files. Now that you've read the introduction, let's look at what's actually inside the first module `00-introduction`:

| File / folder | What it's for |
|---|---|
| `00-introduction.html` | Unique to this first lesson; most modules will just come with objectives, activity, supporting data, and a script that checks your solution to the activity.
| `learning-materials` | A set of files that indicate references to relevant educational materials for the modules, or perhaps are self-contained documents that provide learning material (article, book, or pdf).
| `learning-objectives.md` | A short list of what you should be able to do by the end of the module. Worth a quick read before you start the hands-on work. |
| `activity.md` | The actual problem set and instructions for the hands-on activity that goes with the lesson. |
| `data/` | Any supporting data files an activity needs (spreadsheets, text files, etc.). It's empty for this module since there's no data work yet. |
| `answer-key.py` | A script used to check a solution once you've written one. You won't need it until later modules that actually ask you to write code. |

The number at the front of the folder name (`00-`) tells you the order the
modules go in — `00-introduction` comes first, and later modules will be
`01-...`, `02-...`, and so on, each with this layout.
Once you know your way around one module folder, you know your way around
all of them. 

For most activities you will be creating a Python script that, when run, produces output that can be check with accuracy. So the modules don't come with this script. Additionally, when you run the Activity Quiz AI prompt, two additional files will be created (questions & answers). So a finished module contains the template folders and files, plus additional files that are created as you complete the module.

Be sure to add, commit, and push your changes with git as you work. Similarly, you should pull any changes I make so that you get future modules in your fork of the repository (see Section 8 of the introduction).
